# My Wallpaper Collection

My personal wallpaper collection that fits to all kind of desktop environment.

## Installation

Clone the directory from your directory.

```
cd ~/Pictures # You can also choose a different location
git clone --depth=1 https://github.com/genta-bahana-nagari/wp-collection.git
cd wp-collection/
```

## Update

You can update the wallpapers with

```
cd ~/Pictures/wp-collection
git pull
```
